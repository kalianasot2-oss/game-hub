# Bear Bot — первая рабочая версия

Это стартовая версия Telegram-бота + Mini App в стиле показанного тобой Bear Bot.

## Что уже есть

- `/start`
- проверка подписки на несколько Telegram-каналов
- кнопка «Готово»
- серия дней до 21
- бесплатная попытка раз в 24 часа
- шанс, начинающийся с 5%
- кнопка «Открыть рулетку»
- Mini App с большим колесом
- призы и вероятности на сервере
- история выигрышей в SQLite
- защита от повторного использования одной бесплатной попытки
- простой админский endpoint для просмотра статистики

## Запуск

1. Создай бота через @BotFather и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Заполни `BOT_TOKEN`, `WEBAPP_URL`, `REQUIRED_CHANNELS`.
4. Добавь бота администратором в каналы, которые проверяются — это нужно для `getChatMember`.
5. Установи зависимости:

```bash
pip install -r requirements.txt
```

6. Запусти сервер:

```bash
python app.py
```

7. Для Telegram Mini App нужен HTTPS-адрес. Например, размести проект на VPS с Nginx/HTTPS или используй другой HTTPS reverse proxy.
8. Укажи этот HTTPS-адрес в `WEBAPP_URL`.

## Важно

Не вставляй токен бота в исходники и не публикуй `.env`.

В этой версии реальные Telegram Gifts не выдаются автоматически: приз записывается в базу. Следующим этапом можно подключить реальную выдачу подарков/Stars и оплату платных прокрутов.
